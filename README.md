# 🖊️ Day 1 - Note-Taking CLI App

Hey there! 👋  
Welcome to **Day 1** of my **#30DaysOfPythonChallenge**. To kick things off, I built a simple but handy command-line app for taking notes — perfect for jotting down ideas on the fly.

---

## 📌 What’s This About?
Today’s focus: **Programming Basics** — learning how to write a program that interacts with users directly through the command line.

---

## 💭 So, What’s a Program?
In simple terms, a program is just a list of instructions that tells your computer what to do.  
This project is a great example — it lets you type in notes, saves them with timestamps, and lets you read them later. Think of it as your minimalist digital notebook, right in the terminal.

---

## ✨ Features

Here’s what the app can do:
- ✍️ Take notes right from the command line
- 🕒 Add timestamps to every note automatically
- 💾 Save all notes to a file (so they don’t vanish)
- 📖 View everything you've written so far
- ⚙️ Simple, beginner-friendly interface

---

## 🛠️ Tech Stuff

Built with:
- 🐍 **Python 3**
- 📂 File handling for reading/writing notes
- 🗓️ The `datetime` module to keep track of when you wrote each note
